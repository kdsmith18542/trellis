# Trellis

Trellis is an open-source .NET blockchain development kit with a full reference implementation in F#.

Packages:

- `Trellis.Chain`: core types, crypto, consensus, storage, and tokenomics.
- `Trellis.Node`: runnable node host with REST, WebSocket streaming, and explorer assets.
- `Trellis.CLI`: `trellis` tool for project bootstrap and local node workflows.
- `Trellis.Templates`: `dotnet new trellis-chain` template package.
- `Trellis.Wallet`: Avalonia desktop wallet package.

Getting started and full docs:

- Repository: https://github.com/trellis/trellis
- Docs: https://github.com/trellis/trellis/tree/main/docs
