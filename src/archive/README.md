# Archived Projects

These projects were part of the original Trellis L1 blockchain vision (2024–2026). They were archived in May 2026 when the project pivoted from a standalone L1 to a reference implementation + dev kit + educational resource.

| Project | Lines | Purpose | Why archived |
|---------|-------|---------|-------------|
| `Testnet` | 1,670 | Multi-node testnet orchestrator | Duplicated by Docker dev-net |
| `Beta` | 859 | Corporate validator program | L1 operational tooling |
| `Indexer` | 391 | PostgreSQL compliance indexer | Enterprise add-on, not core |
| `Regnet` | 609 | Regression test runner | Duplicated by Trellis.Tests |

These projects referenced stale types from before the core canonicalization and may not compile. They are preserved as documentation of the project's architectural evolution.
